# Hacia una ley de fomento de la Industria con Software

Documento de trabajo con una propuesta para renovar el régimen de promoción de la industria del software argentina y convertirlo en un engranaje del desarrollo nacional.

**Leer en línea:** https://leito-monk.github.io/ley-de-software/

## Contenido

- `index.html` — versión minimalista del documento, autocontenida (HTML + CSS).
- `Texto sobre nueva ley de software.md` — fuente en Markdown.

## Publicación

Sitio estático publicado con GitHub Pages desde la rama `main`, carpeta raíz.

Para actualizar el sitio, editá `index.html` y subí los cambios:

```bash
git add index.html
git commit -m "Actualiza el documento"
git push
```
